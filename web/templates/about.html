About gingiCHARM

gingiCHARM is a browser GUI for Porphyromonas gingivalis genome characterisation. It runs virulence-factor screening, fimA / mfa-operon / rag / K-antigen typing and functional categorisation from a single curated reference database.

The backend is the pgvfdb, fimtyping, mfatyping, ragtyping, kantigen and pgfunc Python modules of the pgtoolkit package. The web app calls them, collects the results, and renders them as tables you can browse and download as TSV.
